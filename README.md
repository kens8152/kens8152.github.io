# Justin Bieber Fan Page

A single-page fan website built only with HTML, vanilla CSS and vanilla JavaScript.

## Run locally

1. Open this folder in VS Code.
2. Open `fanpage.html` with the Live Server extension.
3. Edit, save and refresh the browser.

## Files to submit

- `fanpage.html`
- `style.css`
- `script.js`

The page includes a responsive layout, biography, facts, music eras, dark/light theme, random fact generator, surprise interaction, scroll animation and quiz.
